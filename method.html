Scene 03 / Method

Inspectable additive scoring

PassGuard is a local rule engine. PassGuard.getScore(password) returns 0–100 in the browser. Passwords are never sent to a server.

Bands

0–19     Very Weak
20–39    Weak
40–59    Medium
60–79    Strong
80–100   Very Strong

Credits

Length (up to 40), character classes (lower, upper, digit, special), uniqueness, and mixed-length bonuses.

Penalties

Repeats, sequences, keyboard walks, calendar years, dictionary stems, digits-only, and short length.

Hard caps (security)

Exact common-list hits are capped at Very Weak. Leetspeak variants of common passwords are capped at Weak. The labelled weak set is designed for a 0% false-negative rate (weak never scored Strong / Very Strong).

Crack time

An educational estimate only — Instantly, minutes, days, years, centuries. It is not a real-world guarantee.

Comparison

Dropbox zxcvbn is loaded client-side in the lab. Agreement is reported as a KPI. Disagreement is expected: zxcvbn is statistical; PassGuard is a transparent viva-ready rule sheet.

Source of truth: js/passguard.js. Tests: npm test or node js/run-tests.js.
